  • 2008
  • Wii
  • Nintendo

History

Bikes, wheel-shaped shells, and online play in the Kart that sold with a plastic wheel.

It is the Wii Mario Kart, not Mario Kart 8.

Mario Kart Wii is recorded here as a 2008 game. The lead system is Wii, 7th generation, motion home console. Wii is the motion-control home console. Some games use the remote, and some are ordinary pad games that happen to be on that hardware. Every other Wii game in this catalog is on the Wii page.

This slug names Wii only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Racing. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2008-04-27; the user rating is 4.30 out of 5 from 309 ratings; the ESRB label on the card is Everyone. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Mario Kart. Other Mario Kart pages in the catalog run from 1992 to 2017, including Super Mario Kart, Mario Kart 64, Mario Kart: Super Circuit, Mario Kart: Double Dash, Mario Kart DS.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Mario Kart list.

RAWG's own platform list for this record is wii. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.

Related games are ordinary links inside this catalog: same series, same franchise, the same Nintendo system, and the same developer when RAWG names one. They are for browsing. Nothing in those lists is for sale, and none of them is a copy of the game.

The official-option note further down names a public Nintendo page when this catalog has one, and it asks you to confirm the title is still offered. Where to Play does not host this game.
