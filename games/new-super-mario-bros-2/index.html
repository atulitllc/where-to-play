History

New Super Mario Bros. 2 is a 2012 release on Nintendo 3DS. RAWG files it among Platformer.

This catalog keeps it on Nintendo 3DS. Any later re-release is a different page when it is a separate game, not a guess about a current listing.

New Super Mario Bros. 2 is recorded here as a 2012 game. The lead system is Nintendo 3DS, 8th generation, 3D handheld. Nintendo 3DS is the later dual-screen handheld, including stereoscopic 3D on titles that use it. Nintendo no longer runs that system's digital catalog. Every other Nintendo 3DS game in this catalog is on the Nintendo 3DS page.

This slug names Nintendo 3DS only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads See the RAWG record. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Platformer. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2012-07-28; the user rating is 3.73 out of 5 from 168 ratings; the ESRB label on the card is Everyone. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Mario. Other Mario pages in the catalog run from 1983 to 2012, including Mario Bros., Super Mario Bros., Super Mario Bros.: The Lost Levels, Super Mario Bros. 2, Super Mario Bros. 3. 16 more Mario pages exist here beyond the list.

In this catalog, Mario is the family name. Same franchise lists spin-offs filed under their own heading, plus any further entries that did not fit the series list.

RAWG's own platform list for this record is nintendo-3ds. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
