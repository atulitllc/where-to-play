History

A half-genie dances through towns and transformations on a late color cartridge.

It is the Game Boy Color original of a series that continued long after the handheld ended.

Shantae is recorded here as a 2002 game. The lead system is Game Boy Color, 5th generation, color handheld. Game Boy Color is the color follow-up to Game Boy. It plays many older Game Boy cartridges and adds color-native games. Every other Game Boy Color game in this catalog is on the Game Boy Color page.

This slug names Game Boy Color only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads WayForward. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG does not list genres on this record. The page does not invent any.

Series context: this title belongs with Shantae. Other Shantae pages in the catalog run from 2002 to 2016, including Shantae and the Pirate's Curse, Shantae: Risky's Revenge - Director's Cut, Shantae: Half-Genie Hero.

In this catalog, Shantae is the family name. Same franchise lists spin-offs filed under their own heading, plus any further entries that did not fit the series list.
