History

Mario Party 4 is a 2002 release on GameCube. RAWG files it among Board Games.

This catalog keeps it on GameCube.

Mario Party 4 is recorded here as a 2002 game. The lead system is GameCube, 6th generation, disc home console. GameCube is Nintendo's disc home console of the sixth generation. This page records the disc release, not a later reissue. Every other GameCube game in this catalog is on the GameCube page.

This slug names GameCube only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads See the RAWG record. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Board Games. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2002-10-21; the user rating is 3.96 out of 5 from 50 ratings; the ESRB label on the card is Everyone. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Mario Party. Other Mario Party pages in the catalog run from 1998 to 2007, including Mario Party, Mario Party 2, Mario Party 3, Mario Party 5, Mario Party 6.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Mario Party list.

RAWG's own platform list for this record is gamecube. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.

Related games are ordinary links inside this catalog: same series, same franchise, the same Nintendo system, and the same developer when RAWG names one. They are for browsing. Nothing in those lists is for sale, and none of them is a copy of the game.
