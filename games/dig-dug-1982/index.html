Dig Dug (1982) is recorded here as a 1982 game. The lead system is NES, 3rd generation, 8-bit home console. The NES is Nintendo's 8-bit home console, the Famicom in Japan. Games shipped on cartridges, and the library set the pattern for side-scrolling platformers. Every other NES game in this catalog is on the NES page.

This is one page for the same game on more than one Nintendo system. Also named here: Game Boy and Game Boy Advance. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.
