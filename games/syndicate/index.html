History

Syndicate is a 1993 release on SNES. RAWG files it among Action.

This catalog keeps it on SNES. Any later re-release is a different page when it is a separate game, not a guess about a current listing.

Syndicate is recorded here as a 1993 game. The lead system is SNES, 4th generation, 16-bit home console. The Super Nintendo is the 16-bit home console that followed, with a deeper color range and a library of platformers, racers, and role-playing games. Every other SNES game in this catalog is on the SNES page.

This slug names SNES only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads See the RAWG record. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Action. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 1993-06-06; the user rating is 4.31 out of 5 from 52 ratings; the ESRB label on the card is Teen. Those fields belong to RAWG. This page does not add a score of its own.

Syndicate is not grouped under one of the series names this catalog matches by title. The related links then point at other SNES games from nearby years, and at games that share the first RAWG developer when one is listed.
