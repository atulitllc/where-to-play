Luigi's Mansion

  • 2001
  • GameCube and Nintendo 3DS
  • Nintendo
  • 6th generation

History

Luigi vacuums ghosts in a flashlight tour of a locked house, room by room.

It is the GameCube launch game that started the Luigi's Mansion series. Later numbered games are sequels, not this mansion.

Luigi's Mansion is recorded here as a 2001 game. The lead system is GameCube, 6th generation, disc home console. GameCube is Nintendo's disc home console of the sixth generation. This page records the disc release, not a later reissue. Every other GameCube game in this catalog is on the GameCube page.

This is one page for the same game on more than one Nintendo system. Also named here: Nintendo 3DS. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.

The credit chip on this page reads Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Adventure, Action. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2001-09-14; the user rating is 4.28 out of 5 from 195 ratings. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Luigi's Mansion. Other Luigi's Mansion pages in the catalog run from 2001 to 2013, including Luigi's Mansion: Dark Moon.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Luigi's Mansion list.

RAWG's own platform list for this record is nintendo-3ds, gamecube. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.

Related games are ordinary links inside this catalog: same series, same franchise, the same Nintendo system, and the same developer when RAWG names one. They are for browsing. Nothing in those lists is for sale, and none of them is a copy of the game.

The official-option note further down names a public Nintendo page when this catalog has one, and it asks you to confirm the title is still offered. Where to Play does not host this game.
