The Legend of Zelda: Majora's Mask

  • 2000
  • Nintendo 64
  • Nintendo

History

A three-day cycle over a doomed town, with masks that change how Link moves through it.

It is the darker Nintendo 64 follow-up to Ocarina of Time. The 3DS version is a separate entry.

The Legend of Zelda: Majora's Mask is recorded here as a 2000 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.

This slug names Nintendo 64 only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Adventure, Action. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2000-04-27; the user rating is 4.33 out of 5 from 421 ratings; the ESRB label on the card is Everyone 10+. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with The Legend of Zelda.
