History

Mission mode and online play on a handheld, with courses that use both screens for a map.

It is the DS Mario Kart, between Super Circuit and Mario Kart 7.

Mario Kart DS is recorded here as a 2005 game. The lead system is Nintendo DS, 7th generation, dual-screen handheld. Nintendo DS is the dual-screen handheld. Touch and the second screen are part of how many of these games are built. Every other Nintendo DS game in this catalog is on the Nintendo DS page.

This is one page for the same game on more than one Nintendo system. Also named here: Wii U. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.

The credit chip on this page reads Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Racing. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2005-11-14; the user rating is 4.27 out of 5 from 256 ratings; the ESRB label on the card is Everyone. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Mario Kart. Other Mario Kart pages in the catalog run from 1992 to 2017, including Super Mario Kart, Mario Kart 64, Mario Kart: Super Circuit, Mario Kart: Double Dash, Mario Kart Wii.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Mario Kart list.

RAWG's own platform list for this record is nintendo-ds, wii-u. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
