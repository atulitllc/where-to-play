Dungeon Master is recorded here as a 1987 game. The lead system is SNES, 4th generation, 16-bit home console. The Super Nintendo is the 16-bit home console that followed, with a deeper color range and a library of platformers, racers, and role-playing games. Every other SNES game in this catalog is on the SNES page.

This slug names SNES only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.
