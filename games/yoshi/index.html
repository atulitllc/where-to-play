History

Inside the Yoshi group, Yoshi (1991) leads with NES and RAWG's Puzzle labels.

The same Nintendo release is listed for Game Boy as well as NES. Nothing here is hosted or sold.

Yoshi is recorded here as a 1991 game. The lead system is NES, 3rd generation, 8-bit home console. The NES is Nintendo's 8-bit home console, the Famicom in Japan. Games shipped on cartridges, and the library set the pattern for side-scrolling platformers. Every other NES game in this catalog is on the NES page.

This is one page for the same game on more than one Nintendo system. Also named here: Game Boy. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.

The credit chip on this page reads See the RAWG record. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Puzzle. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 1991-12-14; the user rating is 3.00 out of 5 from 15 ratings. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Yoshi. Other Yoshi pages in the catalog run from 1991 to 2015, including Yoshi's Cookie, Super Mario World 2: Yoshi's Island, Yoshi's Story, Yoshi's Story (1997), Yoshi's Island: Super Mario Advance 3.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Yoshi list.

RAWG's own platform list for this record is nintendo-switch, nintendo-3ds, wii-u, wii, game-boy, nes. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
