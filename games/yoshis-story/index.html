History

A picture-book Yoshi game about eating fruit to clear short, scored pages.

It is the Nintendo 64 Yoshi, softer and shorter than the SNES Yoshi's Island.

Yoshi's Story is recorded here as a 1997 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.

This slug names Nintendo 64 only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads Nintendo. RAWG lists developer Nintendo and publisher Nintendo. If those names disagree with the chip, both stay on the page so the record can be checked.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Yoshi list.
