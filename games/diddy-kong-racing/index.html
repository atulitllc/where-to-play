History

Kart, hovercraft, and plane races on one island hub, with a boss at the end of each world.

Rare's Nintendo 64 racer, a rival to Mario Kart 64 in the same generation.

Diddy Kong Racing is recorded here as a 1997 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.
