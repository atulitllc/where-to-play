History

Frogger (1981) is a 1981 release on SNES and Game Boy. RAWG files it among Arcade, Action.

This catalog keeps it on SNES and Game Boy. Any later re-release is a different page when it is a separate game, not a guess about a current listing.

Frogger (1981) is recorded here as a 1981 game. The lead system is SNES, 4th generation, 16-bit home console. The Super Nintendo is the 16-bit home console that followed, with a deeper color range and a library of platformers, racers, and role-playing games. Every other SNES game in this catalog is on the SNES page.

This is one page for the same game on more than one Nintendo system. Also named here: Game Boy and Game Boy Color. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.
