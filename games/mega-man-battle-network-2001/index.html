Mega Man Battle Network is recorded here as a 2001 game. The lead system is Game Boy Advance, 6th generation, 32-bit handheld. Game Boy Advance is the widescreen handheld of the early 2000s, still on cartridges, with a library that sits between SNES-style games and later dual-screen designs. Every other Game Boy Advance game in this catalog is on the Game Boy Advance page.
