History

Super Mario World: Super Mario Advance 2 is a 2001 release on Game Boy Advance. RAWG files it among Platformer, Action.

This catalog keeps it on Game Boy Advance. Any later re-release is a different page when it is a separate game, not a guess about a current listing.

Super Mario World: Super Mario Advance 2 is recorded here as a 2001 game. The lead system is Game Boy Advance, 6th generation, 32-bit handheld. Game Boy Advance is the widescreen handheld of the early 2000s, still on cartridges, with a library that sits between SNES-style games and later dual-screen designs. Every other Game Boy Advance game in this catalog is on the Game Boy Advance page.

This slug names Game Boy Advance only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.
