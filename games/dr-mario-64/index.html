History

Dr. Mario 64 is a 2001 release on Nintendo 64. RAWG files it among Puzzle.

This catalog keeps it on Nintendo 64.

Dr. Mario 64 is recorded here as a 2001 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.

This slug names Nintendo 64 only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads See the RAWG record. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Puzzle. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2001-04-08; the user rating is 4.17 out of 5 from 6 ratings. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Dr. Mario. Other Dr. Mario pages in the catalog run from 1990 to 2001, including Dr. Mario.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Dr. Mario list.

RAWG's own platform list for this record is nintendo-64. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
