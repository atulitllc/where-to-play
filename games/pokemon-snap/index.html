History

An on-rails photo safari scores you on how well you frame Pokemon, not on battles.

It is the Nintendo 64 original. A much later Switch game, New Pokemon Snap, is its own entry.

Pokemon Snap is recorded here as a 1999 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.

This is one page for the same game on more than one Nintendo system. Also named here: Wii and Wii U. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.

The credit chip on this page reads HAL Laboratory / Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Simulation. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 1999-03-21; the user rating is 3.95 out of 5 from 162 ratings; the ESRB label on the card is Everyone. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Pokemon. Other Pokemon pages in the catalog run from 1996 to 2003, including Pocket Monsters (Pokemon Green Version), Pokemon Red, Pokemon Trading Card Game, Pokémon Yellow Version: Special Pikachu Edition, Pokemon Gold. 21 more Pokemon pages exist here beyond the list.

In this catalog, Pokemon is the family name. Same franchise lists spin-offs filed under their own heading, plus any further entries that did not fit the series list.

RAWG's own platform list for this record is nintendo-switch, wii-u, wii, nintendo-64. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
