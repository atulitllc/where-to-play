Super Smash Bros.

  • 1999
  • Nintendo 64 and Wii U
  • HAL Laboratory / Nintendo
  • 5th generation

History

Nintendo characters knock each other off floating arenas in a four-player fighting game.

It is the first Smash Bros., the Nintendo 64 original of a series that grew on every home console after.

Super Smash Bros. is recorded here as a 1999 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.

This is one page for the same game on more than one Nintendo system. Also named here: Wii U. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.

The credit chip on this page reads HAL Laboratory / Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Arcade, Action, Fighting. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2014-09-13; the user rating is 4.11 out of 5 from 204 ratings; the ESRB label on the card is Everyone 10+. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Super Smash Bros.. Other Super Smash Bros. pages in the catalog run from 1999 to 2014, including Super Smash Bros. (1999), Super Smash Bros. Melee, Super Smash Bros. Brawl, Super Smash Bros. for Nintendo 3DS, Super Smash Bros. for Wii U.

The wider family in this catalog is Nintendo crossover. Those pages are linked under Same franchise, separate from the tighter Super Smash Bros. list.

RAWG's own platform list for this record is wii-u. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.

Related games are ordinary links inside this catalog: same series, same franchise, the same Nintendo system, and the same developer when RAWG names one. They are for browsing. Nothing in those lists is for sale, and none of them is a copy of the game.
