The Legend of Zelda: The Minish Cap

  • 2004

  • 6th generation

History

Towns and dungeons change scale when Link shrinks to the size of the Minish.

It is a complete Game Boy Advance Zelda, not a port of an earlier console game.

The Legend of Zelda: The Minish Cap is recorded here as a 2004 game. The lead system is Game Boy Advance, 6th generation, 32-bit handheld. Game Boy Advance is the widescreen handheld of the early 2000s, still on cartridges, with a library that sits between SNES-style games and later dual-screen designs. Every other Game Boy Advance game in this catalog is on the Game Boy Advance page.

This is one page for the same game on more than one Nintendo system. Also named here: Wii U and Nintendo 3DS. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.

The credit chip on this page reads Flagship / Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Adventure, Action, RPG. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.
