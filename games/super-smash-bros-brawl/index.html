History

A large roster, a story mode called the Subspace Emissary, and stage hazards turned up.

It is the Wii Smash, between Melee and the 3DS and Wii U games.

Super Smash Bros. Brawl is recorded here as a 2008 game. The lead system is Wii, 7th generation, motion home console. Wii is the motion-control home console. Some games use the remote, and some are ordinary pad games that happen to be on that hardware. Every other Wii game in this catalog is on the Wii page.

This slug names Wii only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads Sora Ltd. / Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Casual, Action, Fighting. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2008-03-09; the user rating is 4.31 out of 5 from 312 ratings; the ESRB label on the card is Teen. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Super Smash Bros.. Other Super Smash Bros. pages in the catalog run from 1999 to 2014, including Super Smash Bros., Super Smash Bros. (1999), Super Smash Bros. Melee, Super Smash Bros. for Nintendo 3DS, Super Smash Bros. for Wii U.

The wider family in this catalog is Nintendo crossover. Those pages are linked under Same franchise, separate from the tighter Super Smash Bros. list.

RAWG's own platform list for this record is wii. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
