History

Mode 7 tracks, slippery handling, and items that still define the series.

It is the SNES original, the first Mario Kart, not a later game that reused the cast.

Super Mario Kart is recorded here as a 1992 game. The lead system is SNES, 4th generation, 16-bit home console. The Super Nintendo is the 16-bit home console that followed, with a deeper color range and a library of platformers, racers, and role-playing games. Every other SNES game in this catalog is on the SNES page.

This is one page for the same game on more than one Nintendo system. Also named here: Wii and Wii U and Nintendo 3DS. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.

The credit chip on this page reads Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Racing. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 1993-08-27; the user rating is 4.06 out of 5 from 254 ratings; the ESRB label on the card is Everyone. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Mario Kart. Other Mario Kart pages in the catalog run from 1992 to 2017, including Mario Kart 64, Mario Kart: Super Circuit, Mario Kart: Double Dash, Mario Kart DS, Mario Kart Wii.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Mario Kart list.

RAWG's own platform list for this record is nintendo-switch, nintendo-3ds, wii-u, wii, snes. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
