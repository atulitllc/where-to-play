Resident Evil - Code: Veronica X is recorded here as a 2001 game. The lead system is GameCube, 6th generation, disc home console. GameCube is Nintendo's disc home console of the sixth generation. This page records the disc release, not a later reissue. Every other GameCube game in this catalog is on the GameCube page.

This slug names GameCube only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.
