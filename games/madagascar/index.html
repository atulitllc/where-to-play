Madagascar is recorded here as a 2005 game. The lead system is Game Boy Advance, 6th generation, 32-bit handheld. Game Boy Advance is the widescreen handheld of the early 2000s, still on cartridges, with a library that sits between SNES-style games and later dual-screen designs. Every other Game Boy Advance game in this catalog is on the Game Boy Advance page.

This is one page for the same game on more than one Nintendo system. Also named here: GameCube and Nintendo DS. A remake, or a release that is a different work, gets its own page. The year goes in the name when two slugs would otherwise collide.
