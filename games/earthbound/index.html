History

Ness and friends walk a modern America-like world, fighting with psychic powers and baseball bats.

It is the SNES Mother game, the cult RPG later players met through reissues and the series' reputation.

EarthBound is recorded here as a 1994 game. The lead system is SNES, 4th generation, 16-bit home console. The Super Nintendo is the 16-bit home console that followed, with a deeper color range and a library of platformers, racers, and role-playing games. Every other SNES game in this catalog is on the SNES page.

This slug names SNES only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads Ape / HAL Laboratory / Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are RPG. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 1994-08-27; the user rating is 4.35 out of 5 from 201 ratings; the ESRB label on the card is Teen. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Mother. Other Mother pages in the catalog run from 1989 to 2006, including Earthbound Beginnings, Mother 3.
