History

2012 brought Kid Icarus: Uprising to Nintendo 3DS; this catalog groups it with Kid Icarus and notes Adventure and Action.

RAWG may show other hardware; this catalog keeps the Nintendo 3DS Nintendo line. RAWG's Adventure and Action labels are shelving, not a review of how it plays.

Kid Icarus: Uprising is recorded here as a 2012 game. The lead system is Nintendo 3DS, 8th generation, 3D handheld. Nintendo 3DS is the later dual-screen handheld, including stereoscopic 3D on titles that use it. Nintendo no longer runs that system's digital catalog. Every other Nintendo 3DS game in this catalog is on the Nintendo 3DS page.

This slug names Nintendo 3DS only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads See the RAWG record. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Adventure, Action. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.
