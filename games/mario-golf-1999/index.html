  • 1999
  • Nintendo 64 and Game Boy Color
  • See the RAWG record
  • 5th generation

History

Stroke play shares a menu with a role-playing mode in Mario Golf (1999). A created golfer's approach still obeys the wind. Camelot's Nintendo 64 game lets a created golfer build stats beside the Mario roster's exhibition rounds, and a separate Game Boy Color version carries the same name.

Club choice and wind still decide an approach before any experience point is spent. The RPG mode is a career wrapper, not a battlefield.

The color handheld's story links are a different cartridge. Putting greens and the trainable golfer are the home version's pair of ideas.
