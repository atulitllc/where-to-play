History

A storybook Mario turns sideways for timed turn-based fights and partner puzzles.

It is the Nintendo 64 start of Paper Mario, before the GameCube sequel and later spin-offs.

Paper Mario is recorded here as a 2000 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.

This slug names Nintendo 64 only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads Intelligent Systems / Nintendo. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are RPG. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 2000-08-11; the user rating is 4.38 out of 5 from 154 ratings; the ESRB label on the card is Everyone. Those fields belong to RAWG. This page does not add a score of its own.

Series context: this title belongs with Paper Mario. Other Paper Mario pages in the catalog run from 2000 to 2016, including Paper Mario: The Thousand-Year Door, Super Paper Mario, Paper Mario: Color Splash.

The wider family in this catalog is Mario. Those pages are linked under Same franchise, separate from the tighter Paper Mario list.

RAWG's own platform list for this record is nintendo-64. This catalog keeps only the Nintendo systems named above. A personal computer, or another company's console, on that list is not a claim that this page covers that version.
