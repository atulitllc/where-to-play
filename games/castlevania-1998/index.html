History

Castlevania (1999) is a 1998 release on Nintendo 64. RAWG files it among Adventure, Action.

This catalog keeps it on Nintendo 64. Any later re-release is a different page when it is a separate game, not a guess about a current listing.

Castlevania (1999) is recorded here as a 1998 game. The lead system is Nintendo 64, 5th generation, 3D home console. Nintendo 64 is the first 3D home console in this catalog. Games used cartridges, and a lot of the library is built around analog-stick movement. Every other Nintendo 64 game in this catalog is on the Nintendo 64 page.

This slug names Nintendo 64 only. RAWG sometimes tags the same record on other hardware. Those tags are not copied here unless this catalog treats them as the same Nintendo release.

The credit chip on this page reads See the RAWG record. RAWG lists no developer name and no publisher name. If those names disagree with the chip, both stay on the page so the record can be checked.

RAWG's genre labels for this record are Adventure, Action. They are a filing aid, not a review written for this page, and not a description of how the game feels in your hands.

The date field is 1998-12-31; the user rating is 3.29 out of 5 from 14 ratings; the ESRB label on the card is Teen. Those fields belong to RAWG. This page does not add a score of its own.
