# Credits

Working title: **Where to Play**.

All interface art (wordmark, screen glyph, favicon) was drawn for this mock. It is not a Nintendo logo and not a cartridge trademark.

Game images are from RAWG only (`https://rawg.io` and `media.rawg.io`). No Nintendo galleries, Wikimedia files, retailer photos, manuals, or screenshots were collected from anywhere else. Each file below is the `background_image` RAWG shows on that game's page. Large files were resized for this static mock; the source URL is the original RAWG CDN address.

Some RAWG records use key art as that hero image. Some use a screenshot they host. Both are attributed the same way.

RAWG's API terms ask for attribution and a link on every page that uses their images. This mock does that in the footer and next to every cover. There was no RAWG API key in the environment, so images were taken from the public game pages' hero image field rather than from `api.rawg.io`.
