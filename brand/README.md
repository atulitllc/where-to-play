# Where to Play — locked mark

Option A: original handheld with a phosphor-green screen. Not a Nintendo logo, not a cartridge, and not a Game Boy drawing. Flat geometric SVG only.

## Files

- `mark.svg` — icon, transparent background, viewBox `0 0 80 72`
- `lockup.svg` — horizontal mark + wordmark, transparent background

## Color

| Role | Hex | Use |
| --- | --- | --- |
| Body | `#1C252B` | Handheld shell |
| Screen well | `#12181C` | Recess behind the glow |
| Phosphor core | `#E9FFC8` | Hot center of the screen |
| Phosphor mid | `#7DFF6A` → `#1FCB62` | Screen glow |
| Phosphor edge | `#0B3D28` | Outer screen |
| Controls | `#3DDC78` | Direction pad, two buttons, side slits |
| Slot | `#0E1518` | Recess under the screen |
| Shell rim | `#3C4A52` | Edge so the body reads on black |
| Triangle | `#F4FFE8` | Play wedge inside the glow |
| Word | `#1C2430` | “Where” and “Play” |
| Accent | `#22C55E` | The word “to” |
| Paper (recommended ground) | `#F6F1E7` | Preview only; SVGs are transparent |

Wordmark is set in Outfit (site display face), weight 560.

The header wordmark is “Where to Play”, with a visible space on each side of “to”. The subtitle under it is NINTENDO CATALOG.

Favicon is this mark on a `#141A1E` squircle, simplified so the green screen still reads at 16px.
